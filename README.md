# 민의 — 정치 인생 시뮬레이터

[게임 플레이](https://songnoin.github.io/minui/)

v0.4 · 2026-10-27

사건에서 선택하면 이야기가 이어집니다. 기본 이야기 모드에서는 캠프가 선거 준비·원화 자금 마련·정책 실무를 맡습니다. 직접 관리 모드로도 바꿀 수 있습니다.

- 실존 정치인 302명 또는 나만의 인물로 가상 정치 인생
- 일반 사건 32개·후속 14개·선택 138개
- 청탁·낙하산·특혜·은폐 등 비리의 유혹과 관계의 빚·폭로 후폭풍
- 선택 전 보상 수치 숨김, 직전 선택 결과를 다음 사건 위에 표시
- 기존 v1/v2/v3 저장 이어하기

실존 인물로 한 선택도 플레이어가 만든 가상 커리어이며 실제 행적을 뜻하지 않습니다. 비리 사건의 제안자와 상황은 가상입니다.

플레이 기록은 브라우저에 저장됩니다. 기존 게임의 기록은 JSON 내보내기/불러오기로 옮길 수 있습니다.

이 저장소에는 독립 실행 HTML, README, Pages 설정만 포함합니다. 개발 작업 기록, 계정 정보, 실제 플레이 저장 데이터는 포함하지 않습니다.
