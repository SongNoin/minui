# 민의 — 내가 정치인이 된다면

[게임 플레이](https://songnoin.github.io/minui/?v=0.5)

v0.5 · 2026-10-28

첫 선거까지 일곱 번의 결정으로 나의 정치 스타일을 알아봅니다. 대표 공약과 출마, 감당할 비용, 조직의 거래를 직접 선택합니다.

- 실존 정치인 302명 또는 나의 이름으로 시작하는 가상 인생
- 사건과 선택이 먼저 보이는 화면, 선택 뒤의 반응과 나의 별명
- 거래를 수락하거나 깨면 동료가 떠나고 조직이 경쟁 캠프로 이동
- 개표에서 후보별 득표율·선거비용·얻은 동료·남은 빚 확인
- 다음 출마·정책·개인자금은 직접 결정, 반복 일상은 자동
- 이전 v1~v4 기록 이어하기, 최근 5개 인생의 관계와 선택 보관

선택 전 능력치 보상은 숨기되 실제로 투입할 원화 비용은 표시합니다. 선거 제도와 자금 규칙을 참고했으며 세부 절차와 비용은 게임용으로 축약했습니다.

실제 인물의 이름과 공개 이력을 참고한 공통 가상 재시작입니다. 게임의 사건·관계·선택은 실제 행적이나 평가가 아닙니다. 첫 선거 이후 모든 선거에 개별 장편 시나리오가 있는 것은 아닙니다.

플레이 기록은 브라우저에 저장됩니다. 다른 기기로 옮기려면 JSON 내보내기와 불러오기를 사용하세요.

이 저장소에는 독립 실행 HTML, README, Pages 설정만 포함합니다. 개발 작업 기록, 계정 정보, 실제 플레이 저장 데이터는 포함하지 않습니다.
